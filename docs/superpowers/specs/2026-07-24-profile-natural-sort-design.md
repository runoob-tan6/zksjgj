# v3 剖面图自然数值排序设计

## 目标

剖面图树节点按名称中的数值大小显示，确保 `H1` 后依次为 `H2`、`H10`，而不是字符串顺序的 `H1`、`H10`、`H2`。不改变文件名、模型顺序、保存顺序或其他 UI 行为。

## 排序规则

合法剖面名为 `H/Z + 数字`。列表先按字母前缀排序，再把数字部分转换为整数排序，因此 `H1、H2、H10、Z1、Z2、Z10` 顺序固定。若内存中出现不符合现有命名规则的旧名称，则将其稳定放在合法名称之后，并按不区分大小写的文本排序，避免刷新树时异常。

## 实现范围

在 `main_window.py` 增加一个私有剖面名排序键，并只替换剖面图节点构建处的 `sorted()` 键。钻孔、附属文件和柱状图排序保持原样。

## 测试

UI 回归测试构造乱序的 H、Z 剖面名，刷新树后直接读取“剖面图”节点的子项文本，断言其为自然数值顺序。完整 pytest、Ruff、mypy、v2 哈希和 EXE 冒烟继续通过。
