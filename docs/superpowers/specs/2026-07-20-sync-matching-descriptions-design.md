# v3 相同地层描述确认同步设计

## 目标

编辑岩性描述时，继续自动填充其他钻孔中地层条件相同的空描述；如果其他匹配层的非空描述与源层修改前描述完全相同，则提示用户是否把这些描述一起更新为新文本。

## 匹配规则

候选层必须位于其他钻孔，并且岩性代号、地层时代、风化程度与源层严格相等。

- 空描述候选：保持现有行为，直接填充新描述，不弹窗。
- 相同描述候选：源层修改前描述非空，且目标描述与修改前描述完全相同。存在此类候选时弹出一次确认。
- 其他非空描述：不提示、不覆盖。

选择“是”时，相同描述候选与空描述候选一起更新；选择“否”时，只更新空描述候选。源层本次编辑不因选择“否”而回滚。

## 数据流

`BasicLayerModel.setData()` 已同时持有旧值和新值。描述变更回调与 Qt 信号扩展为五个字符串参数：修改前描述、新描述、岩性代号、地层时代、风化程度。`MainWindow._sync_description()` 使用旧描述分类候选并调用一次 `QMessageBox.question()`。

所有实际更新仍按受影响钻孔拍摄前后快照，合并为一个 `CompositeUndoAction`。撤销/重做继续保持源钻孔为当前钻孔。

## 提示

标题为“同步岩性描述”，正文说明发现的相同描述数量，并询问是否全部同步为新描述。只要不存在非空相同描述候选，就不显示确认框。

## 测试

- 用户选择“是”：相同旧描述和空描述均更新，其他描述不变。
- 用户选择“否”：相同旧描述不变，空描述仍自动填充。
- 没有相同非空描述时不弹窗。
- 确认后的批量更新可以整体撤销和重做，并保持源钻孔选中。
- 全量 pytest、Ruff、mypy、v2 哈希和 EXE 冒烟继续通过。
