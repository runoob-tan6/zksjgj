> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不修改 `v2/` 的前提下，交付严格兼容旧项目文件、采用三栏工作台并强化表格录入的独立 PySide6 `v3` 应用。

**Tech Stack:** Python 3.10+、PySide6 6.6+、openpyxl 3.1+、pytest、pytest-qt、Ruff、mypy、PyInstaller。

```python
# v3/tools/hash_tree.py
from __future__ import annotations

import hashlib
import sys
from pathlib import Path


def hash_tree(root: Path) -> list[str]:
    rows: list[str] = []
    for path in sorted(item for item in root.rglob("*") if item.is_file()):
        digest = hashlib.sha256(path.read_bytes()).hexdigest()
        rows.append(f"{digest}  {path.relative_to(root).as_posix()}")
    return rows


if __name__ == "__main__":
    print("\n".join(hash_tree(Path(sys.argv[1]))))
```

- [ ] **Step 4: 实现文本元数据和纯解析/渲染函数**

```python
# application/ports.py
@dataclass(frozen=True, slots=True)
class SourceDocument:
    path: Path
    original_bytes: bytes
    text: str
    encoding: Literal["utf-8", "gbk"]
    newline: Literal["\n", "\r\n", "\r"]


@dataclass(slots=True)
class LoadedProject:
    project: ProjectData
    documents: dict[Path, SourceDocument]


def encode_document(text: str, source: SourceDocument) -> bytes:
    normalized = text.replace("\r\n", "\n").replace("\r", "\n")
    return normalized.replace("\n", source.newline).encode(source.encoding)
```

解析器只接收 `SourceDocument` 或字节并返回领域数据；渲染器只接收领域数据和来源元数据并返回字节。渲染器集中处理 `★`、16 行、空值省略和 `e/f` 两列限制。`LoadedProject` 由应用层持有，使领域模型保持与文件元数据无关。
