# v3 代码审查问题整改 Implementation Plan

**Goal:** 按风险顺序修复已核实的代码审查问题，保持 v3 的 UI、操作逻辑和文件兼容性不变。

**Architecture:** 以 `SaveService`/`SaveTransaction` 为唯一保存边界，把共享规则下沉到 domain/infrastructure，以小型协作者逐步减轻 `MainWindow` 职责。每项整改独立测试、提交和回归。

**Tech Stack:** Python 3.10+、PySide6、pytest、pytest-qt、Ruff、mypy。
