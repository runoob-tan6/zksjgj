# V4.0 界面改动说明

V4 是从 V3.1 干净复制出的独立版本，V3 源码保持不动。

## 试验数据页

- 每个试验卡片固定高度，不随添加行增长：
  - `.-o` / `.-q`：固定 5 行；
  - `.-m` / `.-n`：固定 5 行；
  - `.-l`：固定 2 行；
  - `.-e` / `.-f`：固定 6 行。
- 超过固定行数时，只在卡片内部滚动，卡片和页面不会被继续拉长。
- 1596×1047 下，取样/标贯/压水/注水四张主卡片完整显示；e/f 固定 6 行、内部滚动；l 通过页面滚动查看。
- 卡片头合并为：`.-后缀` + 名称 + 条数 + 关系标签 + 添加/删除。
- 卡片 footer：条数 · 深度范围 · e/f 每行增量 · 添加一行。
- 关系标签：
  - `.-q`：与取样配对；
  - `.-n`：接标贯后；
  - `.-m`：深度独立。
- `.-m` 压水与 `.-n` 注水仍是两张独立卡片，不强行对齐深度。
- 页面标题区固定显示：`N 类 · N 条 · 总深`。

## 功能保留

- 添加/删除行、右键上方/下方插入、多选批量删除；
- 取样/标贯配对、自动插入标贯、深度同步、样品编号重编号；
- 删除取样时“保留/删除标贯”确认；
- e/f 每行增量、自动生成行、深度同步、缩短行数确认；
- 双击编辑、数值格式化、e/f 百分比计算和 0–100 校验；
- 撤销/重做、保存脏状态、活动编辑器提交；
- 滚动位置、当前单元格、焦点恢复；
- m/n 独立深度；
- 原有菜单、快捷键、树操作、标贯分析、数据文件、原始文本、校验结果。
