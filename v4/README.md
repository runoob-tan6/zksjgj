# 钻孔数据编辑工具 v4.0

v4.0 在 v3.1 基础上优化试验数据页：卡片按内容自适应高度，o/q/n 同屏，m 压水独立成卡；保留原有菜单、快捷键、项目文件格式和全部数据功能。

## 运行

在 Windows 上双击 `run.py`，或在本目录执行：

```powershell
python run.py
```

项目需要 Python 3.10-3.13、PySide6 6.9.x 和 openpyxl 3.1+。PySide6 6.10+ 的
Windows QtCore 依赖外部 ICU，不能用于本项目的单文件打包。

## v4.0 试验数据页改动

- 每个试验卡片固定视口高度，不随添加行增长：
  - `.-o` / `.-q`：5 行；
  - `.-m` / `.-n`：5 行；
  - `.-l`：2 行；
  - `.-e` / `.-f`：6 行。
- 超出固定行数时只在卡片内部滚动，卡片和页面不会被继续拉长。
- 卡片头合并文件名、名称、条数、添加/删除；e/f 的“每行增量”放在 footer。
- 1596×1047 下，取样/标贯/压水/注水四张主卡片完整显示；e/f 固定 6 行、内部滚动；l 通过页面滚动查看。
- `.-q` 标“与取样配对”，`.-n` 标“接标贯后”，`.-m` 标“深度独立”。
- 保存格式、配对、撤销/重做、右键插入/删除、多选删除、滚动/焦点恢复均保持不变。

## 剖面图和柱状图

- 左侧树中的“剖面图”显示 `H1`、`Z1` 等剖面文件组。右键剖面主文件可重命名，主文件及同名前缀的 `.-d0`、`.-g`、`.-k` 等附属文件会在保存时作为一个整体更新。
- “柱状图”中的 `0yzk.-zkt` 保存全部岩钻孔编号，`0nzk.-zkt` 保存全部土钻孔编号。内容按钻孔号自然排序，每行一个编号，最后一行为 `★`。
- 加载项目时如果两个柱状图文件缺失，v4 会在内存中自动生成并列入待保存内容；只有执行“保存数据”后才写入磁盘。
- 新增、复制、删除或修改钻孔编号后，两个柱状图会自动同步；保存前会再次规范化，避免手工编辑造成编号遗漏。

## 视倾角计算

从“工具 → 视倾角计算...”打开独立计算窗口，无需加载项目。

- 走向或倾向可按固定值、范围输入方位角（北0°、东90°、南180°、西270°），真倾角为0°到90°。
- 按走向输入时，选择倾向位于走向顺时针90°或逆时针90°的一侧；按倾向输入时自动推导走向。
- 跨北范围（例如350°至10°）须勾选“跨越0°”，方位范围跨度不超过180°。
- 可以添加、移除剖面，按各剖面的固定方位角计算视倾角及视倾向。范围按走向和倾角的独立组合计算，并检查内部极值。
- 水平层、直立层、范围内倾向反转和无法确定的组合会单独标明。修改输入即清除旧结果，复制内容包含计算参数、公式及提示。
- 该窗口不读写钻孔原始数据文件。

## 日志与备份

- 运行日志写入程序目录下的 `.Data/logs/borehole-v4.log`，按天滚动并保留 30 天；程序目录不可写时自动改用 Windows 本地应用数据目录。
- 项目原文件备份保存在项目的 `tmp` 目录。每个原文件最多保留最近 20 份 `.bak`，保存失败回滚所需的当前备份不会被提前清理。

## 打包

双击 `打包exe.bat`，或执行：

```powershell
python -m PyInstaller --clean --noconfirm borehole_v4.spec
```

打包配置会检查 PySide6 版本；如果版本不是 6.9.x，会在构建开始时直接报错，避免生成启动失败的 EXE。

输出文件为 `dist/钻孔数据编辑工具v4.0.exe`。

## v2 保护

`v2-baseline.sha256` 记录开发开始时 v2 的全部文件路径、大小和 SHA-256。验收时运行：

```powershell
python tools/hash_tree.py ..\v2 --check v2-baseline.sha256
```

v4 不在运行时导入 v2，也不得修改 v2 的任何文件。
