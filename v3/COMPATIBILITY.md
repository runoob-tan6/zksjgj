# v3 兼容性与验收报告

## 结论

v3 从 v2 源码完整复制后独立优化。窗口标题、应用版本、包名、命令名和 EXE 名称更新为 v3；窗口尺寸、菜单、快捷键、分栏、标签页、按钮和正常操作入口保持 v2 行为。本次按需求把树分组“剖面及柱状图”改为“剖面图”、“项目配置文件”改为“柱状图”，并增加剖面文件组右键重命名。

此前 `codex/v3-refactor` 分支的三栏界面没有进入本版本。

## 功能入口

自动化功能清单确认保留以下入口：

- 文件：选择项目、重新加载、打开文件夹、退出。
- 编辑：撤销、恢复。
- 工具：新增钻孔、新增剖面文件、校验项目、导出试验汇总、保存数据。
- 工作区：钻孔树、基本信息、试验数据、标贯分析、数据文件、原始文本、校验结果。
- 树操作：钻孔/剖面复制和删除、剖面文件组重命名、附属文件新增和删除、柱状图文件新增和删除。
- 外部输入：项目文件夹拖放、XLSX/XLS/CSV 表格拖放导入。

源码清单测试要求 v2 的 24 个 Python 模块和全部主要 `MainWindow` 命令方法继续存在；v3 允许新增内部模块但不允许删除基线入口。

## UI 对照

- 最小窗口：980 x 640。
- 默认窗口：1180 x 760。
- 布局：左侧钻孔树、右侧六标签页。
- 六个标签页分别在独立进程中用同一 Qt 版本、窗口尺寸和空项目状态渲染。
- `window.grab()` 不包含操作系统标题栏，因此 v2/v3 允许的标题版本差异被自然排除。
- 六组 PNG 字节完全一致，像素差异为零。

## 文件兼容

合成旧项目覆盖：

- ZK 主文件及固定 16 行字段。
- `.-b/c/d/g/h/q` 已知文件。
- `.-x` 未知钻孔附属文件。
- 剖面主文件和剖面附属文件。
- `0nzk.-zkt` 和 `0yzk.-zkt` 柱状图文件。
- GBK、UTF-8、CRLF 和 LF。

验证结果：只加载不改变任何字节；编辑一个岩性代号只更新 `.-c`；未知附属文件保持原字节；更新文件保留原编码和换行风格。

## 剖面图重命名

- 剖面图列表按字母前缀和数字编号自然排序，例如 `H1、H2、H10`，不再按字符串顺序显示为 `H1、H10、H2`。
- `H8`、`H8.-d0`、`H8.-g`、`H8.-k` 等同名前缀文件作为一个完整剖面组处理。
- 右键重命名会统一更新模型名称和全部目标文件前缀；连续执行 `H8 -> H9 -> H10` 时仍保留最初磁盘名称 `H8`。
- 已存在的模型名称、目标主文件或任一目标附属文件都会阻止重命名，避免覆盖其他数据。
- 保存事务先写入完整新文件组，再删除旧文件组；任一步失败都会回滚，并保留待保存状态供再次执行。

## 柱状图同步

- `0yzk.-zkt` 仅包含全部岩钻孔（ZK）编号，`0nzk.-zkt` 仅包含全部土钻孔（NZK）编号。
- 编号按自然顺序排列，每行一个，最后使用 `★` 结束；没有对应钻孔时内容仅为 `★`。
- 项目加载后若文件缺失，会在内存中自动创建待保存模型，加载过程本身不写磁盘。
- 新增、复制、删除和修改钻孔编号后立即同步；保存摘要和实际保存前再次规范化，重复同步不会把正确文件标记为修改。

## 稳定性修复

1. 多文件保存改为同目录临时写入、持久备份、原子替换和失败逆序回滚。
2. 保存失败不清除钻孔、剖面或柱状图文件的脏状态。
3. 加载、保存、导入和导出使用单一后台任务运行器，拒绝重叠任务并统一释放线程。
4. 关闭窗口时等待后台任务，不再销毁仍运行的 `QThread`。
5. 待删除剖面纳入未保存检查，切换项目或关闭时不会静默丢失操作。
6. LF 文件在 Windows 保存后继续使用 LF，不再被隐式转换为 CRLF。
7. 导入拒绝 `NaN` 和正负无穷深度；导出保留非有限原始文本，避免 openpyxl 静默写成空单元格。
8. 状态栏总深度忽略非有限输入，不再显示 `nan m`。
9. 未加载项目时不生成柱状图模型，空窗口可直接关闭且不会误报未保存修改。
10. 岩性描述同步严格匹配岩性代号、地层时代和风化程度：空描述自动填充；与源层修改前文本完全相同的非空描述经一次确认后批量更新；其他描述保持不变。同步数量提示保持可见，批量同步可在源钻孔整体撤销和重做。
11. 保存 `.-h` 描述文件时仅写入同时具有层底深度和非空描述的完整记录，并清理首尾空白；不再生成空描述行、孤立深度行或孤立描述行。

## 性能优化

- 导出操作只计算一次钻孔自然排序，并把结果复用于试验汇总、钻孔汇总、标贯分析和 CSV 输出。
- 文本保存先做规范化内容比较，未变化文件不进入事务和备份。
- 事务在任何目标替换前先完成全部内容编码、临时写入和原文件备份，减少半提交状态。

## 边界

自动化使用合成项目，不包含用户真实工程数据。文件名、字段顺序、结束标记、编码、换行、保存集合和导出结构已经覆盖；最终用于生产前仍应把一个真实项目复制到临时目录，用现有 CAD/FAS 插件完成一次成图验收。该现场验收只操作项目副本，不应写入原项目或 v2 目录。
